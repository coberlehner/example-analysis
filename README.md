# Text Data Analysis

This project demonstrates the processing and analysis of structured text data using R.

## Overview

The R script reads text-based input data, extracts relevant variables, performs data cleaning and transformation, calculates descriptive statistics and correlations, and visualises trends over time.

## Methods

The analysis includes:

* Data extraction and transformation
* Text-based variable extraction
* Descriptive statistics
* Correlation analysis
* Time-series aggregation
* Data visualisation

## Tools

* **R**
* **dplyr**
* **stringr**
* **ggplot2**

## Files

* `analysis.R` – R code for data processing, analysis and visualisation
* `input_data.txt` – synthetic example data used as input data for the analysis
